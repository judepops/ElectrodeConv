      04

      Can it tell the batches apart? V1, V2 and the baselines

      each spot's tile embeddings are averaged and a classifier is scored on spots it never saw; V2's encoder learns from the labels, so it is retrained once per held-out group and every spot is called by an encoder that never saw it

      balanced accuracy, leave one session out · black tick = chance (0.33) · red tick = imaging cues alone (the bar) · whisker = 90 % interval from resampling the 13 imaging sessions · the highlighted row is V2 (nested: 13 retrained encoders, no permutation p) · the null row is what shuffled labels score (mean and 95th percentile) · recall per batch with 95 % Wilson intervals

      Accept, investigate or reject against Batch_3

      every material feature of a lot is placed against the baseline's normal variation; a frozen rule reads the result
