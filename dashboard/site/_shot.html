      03

      Do the two embeddings match?

      the contrastive loss wants each BSE tile to be most similar to the Inlens image of the same tile

      cosine similarity · rows: BSE z · columns: Inlens z · diagonal = same tile

      tile from a spot the model never trained on row's best match is the true partner row's best match is another tile
      04

      Can it tell the batches apart from the images alone?

      each spot's tile embeddings are averaged and a classifier is scored with whole imaging sessions held out

      balanced accuracy, leave one session out · black tick = chance (0.33) · red tick = what the imaging descriptors alone score (black level, contrast, noise: the bar any material signal must clear) · "mixed" = accuracy on spots whose session holds more than one batch, where imaging cannot be the cue · the highlighted row is the encoder used on this page

      05

      Accept, investigate or reject against Batch_3

      every material feature of a lot is placed against the baseline's normal variation; a frozen rule reads the result

      dot = lot mean minus baseline mean in baseline SD · line = 90 % interval (session-aware) · shaded = ±1.5 SD, the margin

      one site each: the rule returns INSUFFICIENT DATA, the features are still placed against the baseline
